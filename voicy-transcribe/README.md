# voicy-transcribe

音声ファイル（またはVoicyのエピソードURL、実験的機能）を入力すると、ローカルで文字起こし＋要約を行う自分専用のローカルWebアプリです。外部有料APIは使いません。全処理はあなたのパソコンの中だけで完結します。

## 必要なもの

- Python 3.9以上
- [Ollama](https://ollama.com)（要約に使用。ローカルで動くAIです）

## セットアップ

1. Ollamaをインストールし、モデルを取得する
   ```bash
   ollama pull qwen3:8b
   ```
2. 依存パッケージをインストールする
   ```bash
   pip install -r requirements.txt
   ```

## 起動方法

1. ターミナルで以下を実行し、Ollamaを起動しておく（このコマンドはターミナルを閉じるまで動かし続ける必要があります）
   ```bash
   ollama serve
   ```
2. 別のターミナルを開き、アプリを起動する（**VoicyのURL機能を実際に使う場合は`DRY_RUN=false`が必須**。音声ファイルのアップロードのみ使う場合は不要）
   ```bash
   export DRY_RUN=false
   uvicorn src.main:app --reload
   ```
3. ブラウザで `http://localhost:8000` を開く
4. 音声ファイルを選択するか、VoicyのURLを入力して「実行」を押す

## Voicy URL機能について（実験的）

VoicyのURLを入力する機能は「動けばラッキー」の実験的な機能です。Voicyは公式に音声を外部取得するための手段を用意していないため、うまく取得できないことがあります。その場合は「音声ファイルを手動でアップロードしてください」という案内が表示されるので、その通りにファイルをアップロードしてください（これがこのアプリの正式な使い方です）。

この機能を使う前には、画面に「個人利用の範囲でVoicyから音声データを取得します」という確認が表示されます。これは、Voicyの利用規約を尊重し、自分専用の範囲でのみ使うためのものです。

**安全のためのデフォルト（DRY_RUN）**: 誤って意図せずVoicyへアクセスしてしまうことを防ぐため、`DRY_RUN`環境変数のデフォルトは`true`です。この状態ではVoicy URLを入力してもダミーデータが返るだけで、実際の音声取得は行われません。実際にVoicyから音声を取得したい場合は、起動前に`export DRY_RUN=false`を実行してください（上記「起動方法」参照）。

## トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| 要約が表示されず「要約エンジン（Ollama）に接続できません」と出る | Ollamaが起動していません。ターミナルで `ollama serve` を実行してから、もう一度「実行」を押してください |
| 「対応していない形式です」と出る | mp3 / m4a / wav 以外のファイルは非対応です。ファイル形式を変換してから試してください |
| 「ファイルサイズが上限（500MB）を超えています」と出る | 500MB以下のファイルに分割するか、圧縮してから試してください |
| Voicy URLを入力しても失敗する | 想定内の動作です。「音声ファイルを手動でアップロードしてください」の案内に従って、ファイルをアップロードしてください |
| 文字起こしにとても時間がかかる | 音声が長いほど時間がかかります（目安: 10分の音声で15分以内）。パソコンの性能によってはさらに時間がかかることがあります |

## このアプリでやらないこと

- 話者の聞き分け（複数人の会話を誰が話したか分けること）
- 複数人での同時利用・インターネット上への公開
- Voicyや他サービスへの自動投稿
