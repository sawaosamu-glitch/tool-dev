# 採用停止基準表

| 技術/サービス | 採用停止条件 | 代替案 |
|---|---|---|
| faster-whisper | メンテナンスが1年以上停止し重大な不具合が放置される場合 | openai/whisper（オリジナル実装）またはwhisper.cpp |
| Ollama | プロジェクトが停止、またはローカル実行が有料化される場合 | llama.cpp直接利用、またはLM Studio |
| Qwen3（モデル） | ライセンス変更で商用・個人利用に制限がかかる場合 | 他のApache/MITライセンスの日本語対応OSSモデル（例: ELYZA系） |
| Voicy URL自動取得（FR-EXT-002） | Voicyが利用規約でスクレイピング・自動取得を明確に禁止していることが判明した場合、またはVoicyから停止要請があった場合 | 即座に機能を無効化し、手動アップロードのみの運用に戻す |
| FastAPI | 該当なし（安定した主要フレームワークのため） | Flask |
