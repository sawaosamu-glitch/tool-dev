## 変更履歴

### 2026-08-23: Node不要のローカル単一ファイル版（match.html）

「作ったツールをローカルで使えるようにHTMLファイルにしてほしい、ファイル名はmatch.htmlに」
との要望を受け、`npm run standalone`（`scripts/build-standalone.js`）で `dist/match.html` を
生成できるようにした。CLI・GUIサーバーと同じ`src/lib/*.js`をrequire/module.exportsの行だけ
機械的に取り除いて連結し、ロジックを一切複製せずに完全なブラウザ単体アプリへ変換している。

- 制作中に2件の不具合を発見しその場で修正:
  1. `webContent`内の文字列リテラルに`</script>`が含まれ、埋め込み先の`<script>`タグを
     HTMLパーサーが誤って終端してしまい、後半のスクリプトが本文として表示される不具合。
     `escapeScriptClose`（`</script` → `<\/script`）で解消し、TC-S02で再発防止。
  2. 印刷用ページを新規タブで開く処理を`window.open('')`で実装したところ、ブラウザの
     ポップアップブロッカーに阻まれて開けない事象を確認。Blob URL + `<a target="_blank">`
     方式に変更し、ダウンロード系ボタンと同じ仕組みに統一した。
- テスト: 71件 → **76件**（`tests/e2e/standalone.test.js` 5件追加）。埋め込みロジックが
  `src/lib/*.js`本家と完全に同じ結果を返すことを直接比較で検証（TC-S03）
- 実機確認: ブラウザで問題選択・サイズ変更・カスタムmm・分割印刷（A0→A3）・全ダウンロード
  ボタン・0件選択時のエラー・分割用紙が版面以上のときのエラーを一通り操作して確認
- 更新: `CONSTRAINTS.md`（4d章追加）, `CLAUDE.md`, `README.md`

### 2026-08-23: Web公開用の1ページ版（FR-17, FR-18）

「Webで公開できるようにHTML形式で出力してほしい」との要望を受け、`--web`（CLI）／
「Web公開」チェックボックス（GUI）で `web.html` を追加出力できるようにした。
印刷用POP（用紙サイズ固定・`@page`前提）とは別の出力として設計し、画面幅に応じて
JSで `transform: scale()` を再計算するレスポンシブな1ページに全問題＋解答一覧をまとめた。
外部リソースは一切読み込まず、1ファイルだけで完結する（レンタルサーバー・GitHub Pages等に
このファイル1つをアップロードすれば公開できる）。

- 実装時、`webContent`内で`--pw`/`--ph`（CSS変数）の定義を書き忘れ、見出し帯の虫眼鏡アイコンが
  文字と重なる不具合が発生。ブラウザで目視して発覚し、即修正（`FP`化はせず、その場でテスト
  TC-U51に「--pw/--phが定義されていること」を追加して再発防止）。
- テスト: 63件 → **71件**（Unit +4, E2E +2, GUI +2）、カバレッジ 行97.97%／分岐93.22%
- 実機確認: ブラウザでPC幅・スマホ幅（450px）の両方を目視。ナビゲーションのアンカー
  ジャンプ、解答セクションの内容をアクセシビリティツリー経由で確認
  （非常に縦長なページでbrowserパネルのスクリーンショット機能が一時的に灰色表示になる
  既知の制約があったが、実際のDOM/レイアウトは正しいことを`elementFromPoint`等で確認済み）
- 更新: `docs/SRS.md`（FR-17/18, IN SCOPE）, `docs/SDD.md`（ADR-06）,
  `docs/TEST_PLAN.md`, `CONSTRAINTS.md`（4c章追加）, `CLAUDE.md`, `README.md`

### 2026-08-23: ローカルGUI追加（FR-15, FR-16）

「コマンドではなく画面でサイズ・分割印刷を選びたい」との要望を受け、`npm run gui` で
起動するローカル専用画面（`src/gui-server.js`、127.0.0.1限定）を追加。
`src/index.js` から `build(opts)` を切り出してCLI・GUI共通の実装にし、
GUI側は問題選択・サイズ・分割印刷のフォーム値を `build()` の引数に変換するだけで、
検証・描画ロジックは複製していない（ADR-05）。出力先はCLIの既定と分離し
`dist/gui-output/` 固定、`/preview/` の静的配信はパストラバーサル対策済み。

- テスト: 55件 → **63件**（E2E +8: GUI正常3／異常3／境界2）、カバレッジ 行97.79%／分岐93.02%
- 実機確認: ブラウザでフォーム操作 → A0＋分割印刷（A3×9枚）を画面から生成し、
  「1行1列（1/9）」の版面切り出しが正しいことを目視確認。問題0件選択時のエラー表示も確認
- 更新: `docs/SRS.md`（FR-15/16, IN SCOPE）, `docs/SDD.md`（ADR-05, モジュール表）,
  `docs/TEST_PLAN.md`, `CONSTRAINTS.md`（4b章追加）, `CLAUDE.md`, `README.md`

### 2026-08-23: デザイン刷新とキャラクター名変更

見出し帯が参照写真（黄色斜めストライプ＋提灯＋赤ふちどり文字）を模倣しすぎているとの
指摘を受け、配色・モチーフを「探偵・謎解き風」（濃紺×金×臙脂、虫眼鏡と歯車のアイコン）に
刷新。あわせて「マッチ棒博士S」の名称を「Dr.マッチ棒」に変更。色・アイコンはテストの
検証対象外（座標・本数・検証ロジックとは独立）のため、テスト件数への影響なし。

### 2026-08-23: 大判の分割印刷（FR-13, FR-14）

`--tile <サイズ>` を追加。A0等の大判をA3/A4など家庭・コンビニで印刷できる用紙の
格子に分割し、`<ID>-tiles.html` として追加出力する（既定10mmのりしろ、`--tile-overlap`
で変更可）。版面本体（`.pop`）の設計・CSSは無変更。CSSのクリップ配置のみで実現し、
外部依存パッケージは追加していない。

- テスト: 49件 → **55件**（Unit +4, E2E +2）、カバレッジ 行98.93%／分岐93.50%
- 実機確認: Chromeヘッドレスでタイル出力をスクリーンショットし、隣接タイルの見出しが
  正しく連続することを目視確認
- 更新: `docs/SRS.md`（FR-13/14, RSK-01）, `docs/SDD.md`（ADR-04）,
  `docs/TEST_PLAN.md`, `CONSTRAINTS.md`（3b章追加）, `CLAUDE.md`, `README.md`
