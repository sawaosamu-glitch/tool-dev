# research_v2 — 未解決点の深掘りと結論

## U-01: 「6+9=7」は2本移動で解けるか → **確定：解ける（唯一解 6-3=3）**

7セグメント表示で全スロットの組合せ（数字10×記号2×数字10×等号1×数字10 = 2,000通り）を
全列挙して検証した。

- 総マッチ棒数 19本（6:6 + `+`:2 + 9:6 + `=`:2 + 7:3）
- 2本移動の解: **`6-3=3` の1通りのみ**
- 1本移動の解: **0通り**（＝「2本動かして」という出題文が正しい）

内訳: `+`→`-` で1本、`9`→`3` で1本外し、`7`→`3` に2本足す。外し2本・足し2本で釣り合う。

→ 写真のクイズはそのまま採用できる。信頼度A（全列挙による実測）。

## U-02: 「2コの四角を3コに（2本移動）」は成立するか → **確定：条件付きで成立**

マッチ棒の本数は移動では変わらないため、可能な配置は総本数で決まる。

| 配置 | 必要本数 |
|---|---|
| 四角2コ（離れている） | 8本 |
| 四角3コ（L字に隣接） | 10本 |
| 四角3コ（横一列） | 10本 |

**8本のままでは四角3コは作れない。** よって「はみ出した余りの棒」が必要になる。
写真のPOPでも左右の図から棒がはみ出しており、この構造と一致する。

逆算探索（四角3コの配置から2本を抜いて別位置へ動かした配置を全生成し、
「四角がちょうど2コ」「1本では解けない」「解が1通り」で絞込み）を行い、次を採用した。

```
+---+   +---+---+
|   |   |   |
+---+   +---+---+
```
四角1コ ＋ （四角1コ＋右へはみ出た2本）＝ 10本、四角2コ。
2本を動かすと**四角3コが横一列に並ぶ**。解は1通り、1本では解けない。

→ 写真の出題意図をそのまま再現できる。信頼度A（全列挙による実測）。

## U-03: 「移動」の形式化 → **確定**

配置を「マッチ棒位置の集合」とし、移動本数を `|A \ B|`（ただし `|A| = |B|`）と定義する。
座標をすべて整数にすれば集合演算が文字列一致で行え、判定が完全に決定論的になる。
これにより「解が何通りあるか」を正確に数えられ、良問（唯一解）と複数解の問題を出題前に区別できる。
