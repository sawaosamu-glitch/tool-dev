# failure_patterns

## FP-001 「動かす本数」を検証せずに問題を採用しかけた
- **発生**: 四角クイズの候補図を探索した際、「2本移動で四角3コ」の条件だけで絞り込んだ結果、
  実際には**1本で解けてしまう**図が候補の先頭に来ていた。
- **影響**: そのまま採用していたら「マッチ棒2本を動かして」というPOPを刷った上で、
  参加者が1本で解いてしまい、出題として破綻していた。
- **根本原因**: 「N本で解ける」だけを条件にし、「N-1本以下では解けない」を条件に入れていなかった。
- **恒久対策**: `solveQuiz` が `moves` 未満の全ての手数を探索し、1つでも解があれば
  `solvable-with-fewer-moves` として不合格にする。TC-U24 / TC-U34 / TC-I01 で固定。
- **昇格先**: CONSTRAINTS.md 1章

## FP-002 帯の高さを固定値にして見出しが切れた
- **発生**: 上部の黄色帯に `height: calc(var(--pw) * 0.42)` を固定指定したところ、
  中身（見出し＋サブ帯）が入りきらず、`overflow:hidden` で文字の上下が切れた。
- **影響**: 画面では気づきにくく、印刷して初めて分かる類の欠陥だった。
- **根本原因**: 内容量に依存する高さを固定値で決めた。
- **恒久対策**: 帯の高さは内容から決まる `flex: 0 0 auto` + padding とし、本文側を `flex: 1` で伸縮させる。
- **昇格先**: 版面変更時はブラウザで実寸を目視する（CONSTRAINTS.md 6章）
