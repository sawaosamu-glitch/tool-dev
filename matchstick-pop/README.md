# マッチ棒クイズPOP ジェネレーター

イベント会場に掲示する「挑戦者求ム／Dr.マッチ棒からの挑戦状!!」POPを、問題データから何枚でも生成します。
**マッチ棒の図はSVGで自動描画**し、**「指定した本数でちょうど解けるか」をソルバーが毎回検証**します。

## いちばん短い使い方

```bash
node src/index.js
```

`dist/index.html` をブラウザで開くと、全POPと解答一覧への入口が出ます。

## 画面から生成する（GUI・コマンド操作なし）

ターミナルで打つのがオプション指定（`--size` や `--tile`）だけなら、画面から選ぶこともできます。

```bash
npm run gui
```

表示された `http://127.0.0.1:4949` をブラウザで開くと、次を画面上で選べます。

- **出力する問題**（チェックボックス。「全部選択」「全部解除」あり）
- **版面サイズ**（プルダウン。A4〜A1・B4〜B1、または「カスタム」でmmを直接入力）
- **大判の分割印刷**（チェックを入れると、分割する用紙サイズとのりしろ幅も選べる）

「生成する」を押すとその場で作られ、結果画面に各POPを開くリンクと「分割印刷版」リンクが並びます。
問題データ（`data/quizzes.json`）は変わらず正しさが検証されるので、解けない問題を選んでも安全に弾かれます。

このGUIは `127.0.0.1`（自分のPCの中だけ）で動くローカル専用のツールです。外部への通信は一切行いません。
終了するときはターミナルで `Ctrl+C` を押してください。

## Node.jsなしでローカルで使う（match.html）

Node.jsもターミナルも使わず、**ファイルをダブルクリックするだけ**で使えるバージョンです。

```bash
node scripts/build-standalone.js
```

`dist/match.html` が1つできます。これをコピーしてブラウザで直接開けば、そのまま画面上で

- 出力する問題の選択
- 版面サイズの変更（A4〜A1・B4〜B1・カスタムmm）
- 大判の分割印刷設定

ができ、「全ページを1つのHTMLで保存」「Web公開用の1ページ版を保存」「解答一覧を保存」で
それぞれ`all.html`/`web.html`/`answers.html`をダウンロードできます。各POPの「🖨 印刷用ページを開く」
からは、その場で生成した印刷用ページ（用紙サイズ・案内バナー付き）を新しいタブで開けます。

この`match.html`は`src/lib/*.js`のロジックをそのまま（書き換えずに）1ファイルへ束ねたもので、
CLI・GUIサーバーと出力結果が完全に一致することをテスト（`tests/e2e/standalone.test.js`）で
保証しています。問題データやデザインを変更した場合は、このコマンドを再実行してください。

## Webで公開する

印刷用のPOPとは別に、ブラウザでそのまま見られる「1ページにまとめたWeb公開版」も出力できます。

```bash
node src/index.js --web
```

`dist/web.html` が1ファイルだけ増えます。これは他のファイルへのリンクに依存しない**完全に自己完結したHTML**で、画面幅に合わせて自動で縮小表示されます（印刷用ページは用紙サイズ固定ですが、こちらはスマホでもPCでも見やすいようにレスポンシブになっています）。上部のナビゲーションから各問題へジャンプでき、末尾にスタッフ用の解答も含まれています。

**公開のしかた**: `dist/web.html` を1ファイルだけ、お使いのレンタルサーバー・GitHub Pages・Netlify等にアップロードすれば、そのURLがそのまま公開ページになります。外部の画像・フォント・スクリプトを一切読み込まないため、アップロードするのはこの1ファイルだけで完結します。

GUI（`npm run gui`）からも「Web公開」欄のチェックボックスで同じものを作れます。

## 印刷のしかた（重要）

1. 出したいPOPのHTMLをChromeで開く
2. `⌘ + P`（Windowsは `Ctrl + P`）
3. **用紙サイズ**を、生成時に指定したサイズ（既定はA3）に合わせる
4. **余白を「デフォルト」のまま**にする ← ここを変えるとChromeがCSSの用紙指定を無視して勝手に拡大縮小します
5. **「背景のグラフィック」をON** ← OFFだと黄色と赤の帯が白く飛びます
6. 「PDFに保存」または印刷

A1などの大判は、この手順でPDFにしてから印刷業者に入稿してください。

## サイズを変える

```bash
node src/index.js --size A1
```

指定できるサイズ: `A4 A3 A2 A1 A0 B4 B3 B2 B1`、またはミリ指定の `600x900`。
どのサイズでも**版面の比率と見た目は同じ**です（全寸法をページ幅の比率で定義しているため）。

## A0など大判を、家庭・コンビニのプリンタで分割印刷する

A0はプロッタや業者入稿でないと直接印刷できません。`--tile` を付けると、
指定サイズの版面を**A3やA4など普通のプリンタで刷れる用紙に分割**した
`<ID>-tiles.html` を追加で出力します。

```bash
node src/index.js --size A0 --tile A3
```

- 各シートの左上に「1行1列（1/9）」のように通し番号が印刷されます。並べる順の目印にしてください。
- 隣り合うシートは既定で **10mm重ねて**出力します（貼り合わせのズレ吸収・のりしろ）。
  重ね幅は `--tile-overlap` で変更できます（mm指定、既定10）。

```bash
node src/index.js --size A0 --tile A4 --tile-overlap 15   # A4×多めのシートで、重ねを15mmに
```

印刷手順は通常版と同じです（`⌘/Ctrl + P` → 用紙サイズを**タイルのサイズ**（例: A3）に、
余白は「デフォルト」、背景のグラフィックはON）。全シート印刷し終えたら、
番号順に並べて重なり部分をカットしながら貼り合わせてください。

`--tile` に指定した用紙が `--size` 以上の場合（分割の必要がない場合）はエラーになります。

## 問題を差し替える・追加する

`data/quizzes.json` を編集して、もう一度ビルドするだけです。

### 計算式のクイズ

```json
{
  "id": "EQ-007",
  "type": "equation",
  "difficulty": 2,
  "moves": 2,
  "question": "マッチ棒を2本動かして\n正しい式にせよ",
  "expr": "1+3=8"
}
```

`expr` は数字と `+ - =` だけ。数字は7セグメント表示（電卓の数字の形）でマッチ棒に変換されます。

### 四角のクイズ

```json
{
  "id": "SQ-003",
  "type": "squares",
  "difficulty": 3,
  "moves": 2,
  "question": "マッチ棒2本を動かして\n2コの四角を3コにしなさい",
  "start": ["h:0:0", "h:0:2", "v:0:0", "v:2:0"],
  "w": 4,
  "h": 2,
  "goalSquares": 3
}
```

`start` はマッチ棒1本ずつの位置です。`h:x:y` は「(x,y)から右へ1本」、`v:x:y` は「(x,y)から下へ1本」。
**座標は2刻み**（マッチ棒1本の長さ＝2）なので、格子の交点は 0, 2, 4, 6… になります。
`w` / `h` はマス目の横・縦の数で、この範囲の外にマッチ棒は置けません。

### 追加したら必ず検証する

```bash
node src/index.js --check
```

- 指定した本数で解が存在するか
- **もっと少ない本数で解けてしまわないか**（「2本動かして」なのに1本で解けたら出題ミス）
- 出題時点で既に正解になっていないか

いずれかを満たさない問題があると、ビルドは中止されて理由が表示されます。

## その他のオプション

```bash
node src/index.js --only EQ-001,SQ-001   # 指定IDだけ出力
node src/index.js --out ./output          # 出力先を変える
node src/index.js --data ./別の問題集.json # 別の問題データを使う
node src/index.js --help
```

## 出力されるもの

| ファイル | 中身 |
|---|---|
| `dist/<ID>.html` | POP 1枚（1問1枚） |
| `dist/<ID>-tiles.html` | `--tile` 指定時のみ。上記POPを分割印刷用の用紙サイズに割った複数ページ |
| `dist/all.html` | 全問をまとめて連続印刷する用 |
| `dist/answers.html` | 解答一覧（スタッフ用・A4）。緑の棒＝移動先、薄いグレー＝もとの位置 |
| `dist/web.html` | `--web` 指定時のみ。Web公開用の1ページ版（レスポンシブ・自己完結） |
| `dist/index.html` | 上記への索引 |
