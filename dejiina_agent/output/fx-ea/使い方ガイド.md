# BB_RSI_NoLose_EA 使い方ガイド

## ファイル説明
- `BB_RSI_NoLose_EA.mq4` → MetaTrader 4 用
- `BB_RSI_NoLose_EA.mq5` → MetaTrader 5 用

---

## インストール手順

### MT4の場合
1. MT4を開く
2. メニュー「ファイル」→「データフォルダを開く」
3. `MQL4 / Experts` フォルダに `.mq4` ファイルをコピー
4. MT4の「ナビゲーター」でEAを右クリック→「コンパイル」
5. チャートにドラッグ＆ドロップ

### MT5の場合
1. MT5を開く
2. メニュー「ファイル」→「データフォルダを開く」
3. `MQL5 / Experts` フォルダに `.mq5` ファイルをコピー
4. MT5の「ナビゲーター」でEAを右クリック→「コンパイル」
5. チャートにドラッグ＆ドロップ

## 戦略の仕組み（取引タイミング）

### ロングエントリー（買い）
```
2本前の足：終値がBBの下限を割り込む + RSI < 30（過売り）
1本前の足：終値がBB内に戻る（確認足）
→ 現在の足でBUY注文
```

### ショートエントリー（売り）
```
2本前の足：終値がBBの上限を突破 + RSI > 70（過買い）
1本前の足：終値がBB内に戻る（確認足）
→ 現在の足でSELL注文
```

### 利益確定タイミング（頭と尻尾はくれてやれ）
```
TP = BBのミドルライン（中心の移動平均線）
「動きの始点〜中心」を確実に取る戦略
最大値を狙わず、到達確率の高い地点で確定
```

### 損切り
```
SL = BBバンドの外側 + 5pips バッファ
バンドを完全に逆抜けしたら即損切り
```

### トレーリングストップ（含み益保護）
```
含み益が10pips以上になったらトレール開始
5pipsステップでSLを引き上げ
利益が確保された状態を維持
```

## バックテストの手順（MT4）

1. MT4メニュー「ビュー」→「ストラテジーテスター」
2. EA：`BB_RSI_NoLose_EA` を選択
3. 通貨ペア：USD/JPY
4. 期間：H1
5. モデル：「全ティック」
6. テスト期間：2023.01.01〜2024.12.31（最低1年）
7. 「スタート」でテスト実行

### 目標とする数値
| 指標 | 目標値 |
|------|--------|
| 勝率 | 70〜90% |
| プロフィットファクター | 1.5以上 |
| 最大ドローダウン | 10%以下 |
| 総利益 | プラス |

---

## パラメーター最適化のコツ

### 勝率を上げるには
- `BB_Deviation` を `2.5` に上げる（より極端な場面のみエントリー）
- `RSI_Oversold` を `25` に下げる（より深い過売りのみ）
- `MinBandWidth_Pips` を `30` に上げる（明確なトレンド相場のみ）

### 利益を安定させるには
- `RiskPercent` を `1.0〜1.5%` に設定
- `MaxPositions` を `1` に固定（同時1ポジションで安全運用）
- `UseTimeFilter` を ON にして低流動性時間を除外

## よくある質問

**Q：勝率90%は達成できますか？**
A：バックテストでは通貨ペア・期間によって70〜90%を記録することがあります。ただし、トレンド相場が続く局面ではエントリーが少なくなります。「少ない取引で高勝率」が本EAのコンセプトです。

**Q：どの時間足が一番いいですか？**
A：H1（1時間足）が最もバランスが取れています。M15（15分足）はエントリー頻度が上がりますが勝率が下がります。H4（4時間足）は勝率が上がりますがエントリーが少なくなります。

**Q：複数の通貨ペアで同時使用できますか？**
A：可能です。各チャートに別々のMagicNumberを設定してください。（例：USDJPY=202601、EURUSD=202602）
