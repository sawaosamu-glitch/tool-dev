# スコープ表

## IN SCOPE（MVP対象・V1）
- [ ] 機能A: テキストメモの登録（手入力・貼り付け／タイトル・本文・タグ・登録日時）
- [ ] 機能B: 登録済みメモの一覧・編集・削除
- [ ] 機能C: 全文検索（SQLite FTS5、日本語対応）でメモを検索
- [ ] 機能D: 質問入力 → 関連メモを検索 → 該当箇所を出典（メモへのリンク）付きで提示する「検索ベースQA」
- [ ] 機能E: ローカルLLM（Ollama）が検出できた場合のみ、検索結果を根拠に要約回答を生成する「生成ベースQA」（出典を必ず併記）
- [ ] 機能F: データのローカル永続化（SQLiteファイル）とエクスポート（バックアップ用JSON/Markdown出力）
- [ ] 機能G: タグ・カテゴリによる絞り込み

## OUT OF SCOPE（V1では対象外）
- 画像ファイルのアップロード・保存・OCR解析・画像内容検索
- クラウド同期・複数端末共有・マルチユーザー対応
- 外部API（OpenAI/Claude API等）を用いた課金前提の生成AI連携
- 認証・ログイン機能（ローカル単一ユーザー前提）
- モバイルアプリ化

## DEFER（V2以降で再検討）
- 画像データの蓄積・タグ付け・画像内メモの全文検索
- 画像のOCRテキスト化・画像内容のベクトル検索
- ベクトル埋め込みによる意味検索（ローカル埋め込みモデルの技術検証後に判断）
- 外部API課金プランの選択制導入（ユーザーが望む場合のみ任意で）
- ブラウザ拡張・クリッピング機能（Web記事をワンクリックで登録）
- 「最近見たメモ」「よく参照するメモ」等の想起支援機能（Phase 5レビューOpus役指摘O-010。メモ数が数百〜数千件規模に増え、タグ付けが徹底されない場合の発見可能性課題への対策候補。V1運用開始後のフィードバックを踏まえて優先度を判断）
