# memory-assistant

自分で集めたテキストメモを蓄積・検索し、質問すると出典付きで答えてくれる、あなたのPC上だけで完結する個人用ナレッジベースアプリです。外部サービスへの送信や課金は一切発生しません。

## できること／できないこと

| できること | できないこと（V1時点） |
|---|---|
| メモの登録・編集・削除・一覧表示 | 画像の登録・検索（V2で検討予定） |
| キーワードでの全文検索 | 複数端末での同期・共有 |
| 質問すると関連メモの抜粋を出典付きで表示（検索ベースQA、常に使える） | ログイン・複数ユーザー対応 |
| （Ollamaを追加導入した場合のみ）質問への要約回答生成（生成ベースQA） | 外部AI API（ChatGPT等）を使った回答生成 |

**Ollamaを入れなくても、検索ベースQA（関連メモの抜粋＋出典表示）は最初から使えます。** 生成AIによる要約回答が欲しい場合のみ、下記の「生成AIを使いたい場合（任意）」を行ってください。

## セットアップ手順

### 1. Node.jsを入れる（未導入の場合のみ）

1. https://nodejs.org/ を開く
2. 「LTS」と書かれたバージョン（18以上）をダウンロードしてインストーラーを実行する
3. インストール後、ターミナル（Windowsは「コマンドプロンプト」または「PowerShell」）で以下を実行し、バージョンが表示されればOK
   ```
   node -v
   ```

### 2. アプリを起動する

このフォルダ（`memory-assistant`）でターミナルを開き、以下を順番に実行します。

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開くとアプリが表示されます。

### 3. うまくいかない場合（ネイティブビルドのトラブルシュート）

`npm install`で`better-sqlite3`のビルドに失敗する場合、以下を試してください。

| OS | 対処 |
|---|---|
| Windows | 「Visual Studio Build Tools」をインストールし、「C++によるデスクトップ開発」ワークロードを選択してから再度`npm install`を実行する |
| macOS | ターミナルで`xcode-select --install`を実行し、Xcode Command Line Toolsを導入してから再度`npm install`を実行する |
| Linux | `build-essential`（Debian/Ubuntu系）または相当のビルドツール群を導入してから再度`npm install`を実行する |

それでも解決しない場合は、Node.jsのバージョンを18/20/22のLTS版に変更してから再度試してください。

## 生成AIを使いたい場合（任意）

検索結果をもとに要約回答を生成してほしい場合は、Ollama（無料のローカルAI実行ソフト）を追加で導入します。

1. https://ollama.com/download から、お使いのOS用のOllamaをダウンロード・インストールする
2. インストール後、ターミナルで以下を実行し、既定モデル（qwen3:4b）をダウンロードする（初回のみインターネット接続が必要）
   ```
   ollama pull qwen3:4b
   ```
3. memory-assistantを再起動する。画面上部に「生成AI利用可」と表示されれば成功です

**モデルを変更したい場合**: `config.json`の`ollamaModel`を別のモデル名（例: `qwen3:8b`）に変更し、`ollama pull [モデル名]`でダウンロードしてからアプリを再起動してください。**モデルを変更する場合は、そのモデルの利用規約（ライセンス）を必ず確認してください**（モデルによってはApache 2.0より制約の多いライセンスが設定されている場合があります）。既定のqwen3シリーズはApache 2.0ライセンスです。

## 検索の特性について

この検索方式（SQLite FTS5のtrigram）は、日本語を3文字単位で区切って検索する仕組みです。1文字での検索はできません（3文字以上を入力してください）。また、この方式の特性上、まれに関連性の低い結果が混ざることがあります。より良い結果が出ない場合は、キーワードを変えて試してみてください。

## データが壊れた・消えたときの復元手順

アプリ起動時に「データに問題があります」というエラーが出た場合、以下の手順で直近のバックアップから復元できます。

1. アプリを終了する
2. `data`フォルダの中に`memory-assistant.db-wal`と`memory-assistant.db-shm`という2つのファイルがあれば削除する（無い場合は何もしなくてよい）
3. `backups`フォルダの中から、一番新しい日付のファイルを見つけ、`data/memory-assistant.db`という名前でコピーする（同じ名前の既存ファイルを上書き）
4. アプリを再起動し、正常にトップ画面が表示されることを確認する
5. それでもエラーが出る場合は、1つ前の日付のバックアップファイルで手順2〜4を再度試す

バックアップは起動時・24時間ごと・終了時に自動作成され、直近7世代が保持されます。

## データの場所

| 種類 | 場所 |
|---|---|
| メモ本体 | `data/memory-assistant.db` |
| バックアップ | `backups/`（直近7世代） |
| エクスポート | `exports/`（Markdown/JSON形式で書き出したもの） |
| 設定 | `config.json`（ポート番号・Ollamaモデル名・バックアップ間隔） |
