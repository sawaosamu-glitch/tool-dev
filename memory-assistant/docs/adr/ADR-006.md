## ADR-006: フロントエンドはビルド不要の素のHTML/CSS/JSとする

### 状態
承認

### 決定
ブラウザ側UI（C-09 StaticUI）はReact/Vue等のフレームワークを使わず、Expressの`public/`から配信する素のHTML/CSS/JavaScriptで実装する。

### 理由
- 個人用単一画面アプリ（8章の画面構成）にフレームワーク・ビルドツール（webpack/vite等）は過剰であり依存最小限の方針に反する
- ビルドステップがないため`npm install && npm start`のみでの起動が容易になり、NFR-PORT-001（3OSでのセットアップ容易性）を満たしやすい

### 代替案
| 案 | メリット | デメリット | 不採用理由 |
|---|---|---|---|
| React + Vite | コンポーネント指向で将来の機能追加がしやすい | ビルドツールチェーン・追加依存が増え、セットアップが複雑化 | 単一画面・小規模UIには過剰投資 |

### 変更禁止レベル
L3-柔軟（画面数・複雑度が大きく増えた場合はV2でフレームワーク導入を再検討する）

### 影響を受ける要件
NFR-PORT-001, NFR-USE-001
