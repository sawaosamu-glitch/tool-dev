## ADR-001: Node.js + Express + better-sqlite3 を中核スタックとする

### 状態
承認

### 決定
言語/ランタイムはNode.js、HTTPフレームワークはExpress、DBアクセスはbetter-sqlite3を採用する。

### 理由
- 完全無料・ローカル完結・依存最小限の制約を満たす（research/v1_A_tools.md A1, A2）
- better-sqlite3はFTS5がデフォルト有効でビルドされ、日本語全文検索要件を満たしやすい（research/v1_B_api.md B5）
- MITライセンスで個人・商用問わず自由利用可（research/v1_B_api.md B3）

### 代替案
| 案 | メリット | デメリット | 不採用理由 |
|---|---|---|---|
| Python + FastAPI + sqlite3標準ライブラリ | 型ヒント・自動ドキュメントが強力 | FTS5拡張の扱いがNode版ほど枯れていない、社長の環境準備コストが増える | Node.js単一言語でフロント(素のJS)〜バックエンドを統一できる方が依存が少ない |
| Node.js組み込み `node:sqlite` | 追加パッケージ不要 | 2026年8月時点でRelease Candidate、FTS5がデフォルト無効（research/v1_A_tools.md A1） | 全文検索必須要件と相性が悪い |

### 変更禁止レベル
L1-不変

### 影響を受ける要件
FR-DATA-001〜006, FR-SYS-001〜005, NFR-PORT-001, NFR-MAINT-001
