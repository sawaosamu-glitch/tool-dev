## 4段階展開

| 段階 | 内容 | 期間 | 完了条件 |
|---|---|---|---|
| Stage 1 | `npm install && npm start`でローカル起動し、テスト用メモを数件登録して動作確認 | 初回起動時 | エラーなく起動・登録・検索・質問応答ができる |
| Stage 2 | 実際に使っている過去のメモ・アイデアを5〜10件程度登録し、日常的な検索・質問を試す | 1週間 | 目的の情報を探し出せる、明らかな不具合がない |
| Stage 3 | 継続利用（バックアップ・エクスポートも定期的に試す） | 1ヶ月 | データが消失しない、Ollama連携（導入している場合）が安定動作する |
| Stage 4 | 通常運用 | 継続 | - |
