# 採用停止基準表

| 技術/サービス | 採用停止条件 | 代替案 |
|---|---|---|
| better-sqlite3 | メンテナンスが1年以上停止し、かつ現行Node.js LTSでビルド不能になった場合 | 組み込み`node:sqlite`が安定版(Stable)化し、FTS5対応が公式にサポートされた時点で移行 |
| FTS5 trigramトークナイザー | 実データで検索精度・体感速度が著しく劣化し利用に耐えない場合 | 形態素解析系拡張(lindera-sqlite等)の導入、またはbigram併用への切替 |
| Ollama | 公式が無料ローカル実行を廃止/有料化した場合、またはプライバシーポリシーが変更されローカル処理データを収集する方針になった場合 | 生成ベースQAをV1既定通り無効化し、検索ベースQAのみで運用継続（アプリの必須機能ではないため致命的影響なし） |
| qwen3:4b（既定モデル） | 日本語品質が実用に耐えない、またはApache 2.0ライセンスが変更された場合 | config.jsonのモデル名変更のみで他モデル（gemma3系等）へ切替（FR-ADM-001） |
| Express | セキュリティ脆弱性が長期未修正の場合 | Fastify等の同等軽量フレームワークへの置換（ローカル専用のため影響範囲は限定的） |
